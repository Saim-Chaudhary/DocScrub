# Contributing to DocScrub

Thanks for helping improve DocScrub.

## How to clone the project

```bash
git clone <repository-url>
cd DocScrub
```

## Install dependencies

```bash
uv sync
```

## Run tests

```bash
uv run pytest
```

## Create a pull request

1. Make a small change.
2. Run the tests.
3. Run the linter if needed.
4. Write a clear commit message.
5. Open a pull request and explain what you changed.

Please keep contributions simple, readable, and beginner-friendly.
